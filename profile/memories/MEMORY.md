# Curated Codex Memory

Last reviewed: 2026-07-25 (Asia/Shanghai)

This is supporting context, not authority. Current instructions, repository
state, and fresh evidence win. Do not store secrets, host facts, task logs,
project science, transient incidents, or one-off permissions here.

## Stable Experience

- “Too much output” includes code and documentation as well as replies. Prefer a
  minimal complete result over speculative frameworks, compatibility layers,
  exhaustive matrices, repeated owners, and tutorial-length prose.
- A useful abstraction may be larger than one line, but shared abstraction
  normally waits for a second real use case, an observed stable repetition, or
  an explicit requirement.
- Long discussions have previously lost or repeated settled decisions. When a
  user-selected canonical record exists, update and reread that one record
  instead of reconstructing state from recent turns.
- Persistent App tasks, managed subagents, and external job monitoring are
  different coordination surfaces. Do not transfer failure patterns or
  permissions between them by analogy.
- Profile changes are edited in the portable Git working tree and deployed
  one-way to the current host. Active profile state, another host, sessions,
  credentials, caches, trust, and plugin-managed artifacts are not portable
  sources.

Promote a repeated signal into `AGENTS.md` or a narrow skill only after real use
shows that the model and existing owner do not already handle it.
