# Personal Thread Closeout

Close the current task without turning completion into a retrospective project.
Explicit invocation authorizes the final archive action, but not new
implementation, Git, publication, or unrelated cleanup.

## Prepare The Handoff

Confirm the requested outcome, actual result, changed artifacts, fresh checks,
checks not run, unresolved decisions, external or running work, repository
state, residual risk, and next owner. Leave the task open if material ownership
or completion is unclear.

Default to a compact inline closeout. Write a file only when a real future task
needs a durable continuation and an existing canonical owner or explicit path
is available. Update that owner with current state; do not create a second
ledger, transcript, generic retrospective, or fixed closeout template.

Optionally curate a verified, non-obvious cross-task lesson only when it will
change future work. Put it in the narrowest existing owner and remove
duplicates. Do not preserve transient status, obvious results, unsupported
inference, raw logs, or secrets.

## Archive Last

Prepare the final user-visible result before archival. Then use the product's
native task archive action for this exact current task without asking again.
The native result is the only evidence that archival occurred.

If the archive action is unavailable or fails, report that the task remains
open. Do not emulate it by moving transcript files or editing runtime state.

Read `references/source-notes.md` only when maintaining provenance.
