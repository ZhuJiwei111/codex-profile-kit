# Source Notes

Checked: 2026-07-25 against `codex-cli 0.144.1`.

- Current protocol and trust behavior come from the
  [official Hooks documentation](https://learn.chatgpt.com/docs/hooks) and the
  schema generated by the installed Codex release.
- Native command definitions support shell expansion, run from the task cwd,
  and require review when an unmanaged definition hash changes.
- Local history showed that a task can keep its startup hook definition after
  profile files change. Deleting an old runner inside that task broke every
  later tool call, so handler retirement uses a fresh-task boundary.

The portable profile retains only a Conda-base mutation guard and a
no-auto-resolution guard. It does not bundle copied protocol references,
semantic download/safety handlers, Hookify adapters, or trust state.
