# Phase boundaries

Keep related phases in the same task while the objective, authority, ownership,
and context remain reliable. A phase change does not require a pause or a new
session. Choose the smallest useful coordination action:

- Continue with the existing task when it can still carry the work accurately.
- Compact when context pressure or loss of focus warrants it. Reconcile the
  existing state owner first when possible, then reread relevant decisions and
  source evidence after recovery. No fixed token threshold determines this.
- Hand off when the environment, ownership, scope, or continuity materially
  changes. Link canonical artifacts and preserve the next action and authority.
- Delegate an independent bounded subtask only with user or applicable repository
  authority. Follow `personal-subagent-boundaries`; the main task owns synthesis.
- Clear context only when the user requests a fresh start or the next task has
  no needed continuity. Preserve required state before discarding context.

Compaction can occur mid-phase. Resume from actual artifacts and explicit user
decisions rather than restarting completed work or assuming the summary proves
completion. Existing plans own current state; this reference creates no new
plan, ledger, task, or file-writing authority.
