# Closure Lenses

Read only when the visible decisions appear complete. Use these as prompts for
one silent, materiality-scaled gap scan, not as a questionnaire or checklist:

- outcome, scope, non-goals, decision owner, and acceptance evidence;
- behavior, inputs, outputs, data, state, interfaces, and affected consumers;
- failures, recovery, compatibility, migration, and partial completion;
- permissions, privacy, security, resources, cost, and operational ownership;
- verification, rollout, observability, stop conditions, assumptions, and
  residual risk.

For data, ML, or experiment work, also consider provenance, leakage, splits,
independent units, metrics, baselines, reproducibility, and deployment skew.
Use other domain lenses only when the actual task makes them consequential.

Open a new question only when its answer could change the outcome, contract,
acceptance, or risk. Do not record `N/A` entries.
